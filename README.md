# aredoko

「あれどこだっけ」を見た目の言葉で探せる、Unity エディタの拡張です。

BOOTH や Asset Store で買ったアセットが増えると、商品名やファイル名を覚えていない素材から順に見つからなくなります。
aredoko は手元の unitypackage やフォルダの中身をモデル・テクスチャ・マテリアルの単位で読み込み、「白いフリルのスカート」「古びた木の机」のような日本語で探せるようにするツールです。
3D モデルはレンダリングした見た目そのものをベクトルにするので、ファイル名や商品説明に書かれていない特徴からでも見つかります。

## 特徴

| 特徴             | 内容                                         |
| ---------------- | -------------------------------------------- |
| 見た目で探す     | モデルとテクスチャを画像として埋め込みます   |
| 中身の単位で探す | 商品の中のモデルやテクスチャを結果に出します |
| Unity の中で完結 | 結果からシーンへ置き、インポートできます     |
| 手元だけで動く   | アセットや検索語を外へ送りません             |
| BOOTH の商品情報 | 商品名・ショップ名・タグも検索に使います     |

アバター改変の衣装・髪型・アクセサリーにも、ワールド制作の小物・建物・テクスチャにも使えます。

## 動作環境

Unity 2022.3 以降の Windows 版エディタで動きます。

## BOOTH とのやり取り

BOOTH から取得するのは、誰でも見られる商品ページの公開情報だけです。
BOOTH のログイン情報や購入履歴には触れず、購入したアイテムを自動でダウンロードすることもありません。
