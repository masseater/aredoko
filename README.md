# aredoko

「あれどこだっけ」を見た目の言葉で探せる Unity エディタ拡張。

Unity の中で、プロジェクトや unitypackage に入っているモデル・テクスチャ・マテリアルを「白いフリルのスカート」「古びた木の机」のような日本語で検索できます。
名前を覚えていないアセットも、見た目の特徴から見つけられます。

## 特徴

| 特徴             | 内容                                       |
| ---------------- | ------------------------------------------ |
| Unity の中で検索 | 検索結果からシーンへの配置とインポート     |
| 中身の単位で検索 | パッケージ内のモデル・テクスチャ単位の結果 |
| 手元だけで動作   | アセットや検索語の外部送信なし             |

## 動作環境

| 項目  | 内容                                  |
| ----- | ------------------------------------- |
| Unity | 2022.3.22f1                           |
| OS    | Windows 10・Windows 11 の 64 ビット版 |

Unity の版は VRChat Creator Companion が入れるものと同じです。

## BOOTH・VRChat のアセット

BOOTH の商品ページの URL を登録すると、商品名・ショップ名・タグでも検索できます。
取得するのは誰でも見られる商品ページの公開情報だけで、ログイン情報や購入履歴には触れません。
衣装・髪型・ワールド用の小物は、VRChat のアバター改変やワールド制作での探し方に合わせて検索の精度を調整しています。
